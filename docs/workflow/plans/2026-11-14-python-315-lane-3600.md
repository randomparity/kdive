# Python 3.15 informational CI lane (#3600) — plan

Goal: add a non-gating workflow that resolves, installs, probes and tests kdive under CPython
3.15 and reports the result in its job summary.

Architecture: one new workflow (`.github/workflows/python-315.yml`, one job) relaxes the
3.14-only pins in its own checkout, then runs five `continue-on-error` probes and an
always-green report step. One new guard test runs the workflow's override and report shell
blocks and pins the lane's non-gating shape. A short docs section points contributors at it.
Spec: `docs/workflow/specs/2026-11-14-python-315-lane-3600-design.md`.

Tech stack: GitHub Actions, bash, uv, pytest + pyyaml + stdlib `tomllib`.

Expected implementation size: 230–290 changed lines (M) — workflow ~110, guard ~130,
apt-guard list +1, docs ~20.

## Task 1 — the lane and its guard

Interfaces: the guard locates steps by `name:` — `Relax the 3.14-only pins for this lane`
(override) and `Report` (report); probe step ids `lock`, `sync`, `ruff`, `ty`, `test`; the
report reads `LOCK_OUTCOME`…`TEST_OUTCOME`, `LANE_LOGS`, `GITHUB_STEP_SUMMARY`.

Verification:

- Contract: override relaxes today's `pyproject.toml`. Mode: focused-test —
  `test_override_relaxes_the_current_pyproject`; red before the workflow exists
  (`FileNotFoundError`); green command below.
- Contract: override refuses a drifted file. Mode: focused-test —
  `test_override_refuses_a_drifted_requires_python`; red: no workflow.
- Contract: report always exits 0, lists outcomes, bumps, builds, warns per failure. Mode:
  focused-test — `test_report_lists_outcomes_and_never_fails`; red: no workflow.
- Contract: lane is non-gating and isolated from `ci.yml`. Mode: focused-test —
  `test_lane_is_informational_and_isolated`; red: no workflow.
- Contract: apt bounding covers the lane. Mode: focused-test —
  `test_no_workflow_installs_packages_with_a_bare_apt_get` after adding the name.

Steps:

Workflow shape (`python-315.yml`):

- `name: Python 3.15 (informational)`; `on`: `pull_request.paths` [`pyproject.toml`,
  `uv.lock`, `Dockerfile`, `tests/container/Dockerfile`, `.github/workflows/python-315.yml`],
  `schedule: [{cron: "23 5 * * 1"}]`, `workflow_dispatch`; `permissions: contents: read`;
  `concurrency: {group: python-315-${{ github.ref }}, cancel-in-progress: true}`;
  `defaults.run.shell: bash`.
- job `python-315`, `name: python 3.15 (informational)`, `runs-on: ubuntu-latest`,
  `timeout-minutes: 60`, `env: {UV_PYTHON: "3.15"}`. `LANE_LOGS` is exported by the override
  step through `$GITHUB_ENV` (`runner.temp` is not available in job-level `env`).
- steps: Checkout (`persist-credentials: false`); `Install build headers` →
  `./scripts/apt-install.sh libvirt-dev libffi-dev`; Set up uv (`version: "0.13.8"`,
  `enable-cache: true`, `cache-suffix: py315`); Set up just; override; `lock`; `sync`
  (`if: steps.lock.outcome == 'success'`); `ruff`, `ty`, `test` (each
  `if: steps.sync.outcome == 'success'`); Report (`if: always()`, env outcomes from
  `steps.<id>.outcome`).
- `lock`: `uv lock 2>&1 | tee "$LANE_LOGS/lock.log"`; `sync`:
  `uv sync --locked 2>&1 | tee "$LANE_LOGS/sync.log"`; `ruff`:
  `uv run --no-sync ruff check --target-version py315`; `ty`:
  `uv run --no-sync ty check --python-version 3.15`; `test`:
  `just pull-test-images && just test` with `KDIVE_REQUIRE_DOCKER: "1"`.

Override block (step `Relax the 3.14-only pins for this lane`):

```bash
mkdir -p "${RUNNER_TEMP:-/tmp}/lane"
if [[ -n ${GITHUB_ENV:-} ]]; then echo "LANE_LOGS=$RUNNER_TEMP/lane" >> "$GITHUB_ENV"; fi
pin='requires-python = "==3.14.*"'
if ! grep -qxF "$pin" pyproject.toml; then
  echo "::error::pyproject.toml has no '$pin' line; update this lane's override" >&2
  exit 1
fi
sed -E \
  -e 's/^requires-python = "==3\.14\.\*"$/requires-python = ">=3.14"/' \
  -e 's/^(  "[^"]+)==([^"]+",)$/\1>=\2/' \
  pyproject.toml > pyproject.toml.new
mv pyproject.toml.new pyproject.toml
cat >> pyproject.toml <<'TOML'

[tool.uv]
required-environments = [
  "sys_platform == 'linux' and platform_machine == 'x86_64' and python_version == '3.15'",
]
TOML
grep -nE '^requires-python|^\[tool\.uv\]' pyproject.toml
```

Report block (step `Report`):

```bash
warnings=()
summary() {
  echo "## Python 3.15 lane — linux/x86_64 (informational — never gates)"
  echo
  echo "| probe | outcome |"
  echo "|---|---|"
  for probe in lock sync ruff ty test; do
    var="${probe^^}_OUTCOME"
    outcome="${!var:-}"
    echo "| $probe | ${outcome:-not run} |"
    if [[ $outcome != success ]]; then
      warnings+=("::warning title=Python 3.15 lane::$probe: ${outcome:-not run}")
    fi
  done
  echo
  echo "Forced version changes (uv lock):"
  echo '```'
  grep -E '^(Updated|Added|Removed) ' "${LANE_LOGS:-/nonexistent}/lock.log" 2>/dev/null || echo "(none)"
  echo '```'
  echo "Built from source (no cp315 wheel at the locked version):"
  echo '```'
  grep -E '^ *Built ' "${LANE_LOGS:-/nonexistent}/sync.log" 2>/dev/null || echo "(none)"
  echo '```'
}
summary >> "$GITHUB_STEP_SUMMARY"
if ((${#warnings[@]})); then printf '%s\n' "${warnings[@]}"; fi
```

Guard tests (`tests/guards/test_python_315_workflow.py`), stdlib + pyyaml + pytest:

- `_workflow()` loads the YAML; `_step(name)` finds a step by `name`; `_run(block, cwd, env)`
  runs `bash -euo pipefail -c block` (GitHub's `shell: bash` is `-eo pipefail`; the guard adds `-u`) and returns the result.
- `test_override_relaxes_the_current_pyproject(tmp_path)`: copy the repo `pyproject.toml`
  into `tmp_path`, run the override with `RUNNER_TEMP=tmp_path`, `GITHUB_ENV` unset; assert exit
  0; `tomllib` load: `requires-python == ">=3.14"`, no `"=="` in any entry of
  `project.dependencies` or any `dependency-groups` list, and `tool.uv.required-environments`
  is the one marker string above.
- `test_override_refuses_a_drifted_requires_python(tmp_path)`: copy, replace the pin line with
  `requires-python = "==3.15.*"`, run; assert non-zero, stderr names `requires-python`, file
  bytes unchanged.
- `test_report_lists_outcomes_and_never_fails(tmp_path)`: write `lock.log` with an
  `Updated psycopg v3.3.4 -> v3.3.4, v3.3.9` line and `sync.log` with `      Built cffi==2.0.0`;
  env `LOCK_OUTCOME=success`, `SYNC_OUTCOME=success`, `RUFF_OUTCOME=success`,
  `TY_OUTCOME=failure`, `TEST_OUTCOME=skipped`, `LANE_LOGS`, `GITHUB_STEP_SUMMARY`; assert exit
  0, summary has five rows (`| ty | failure |`, `| test | skipped |`), both log lines, and
  stdout carries exactly two `::warning` lines (runner commands are read from stdout). A second run with no `LANE_LOGS` and no outcome
  variables exits 0 and reports `not run` and `(none)`.
- `test_lane_is_informational_and_isolated()`: lane `on` has no `push`; `permissions ==
  {"contents": "read"}`; the job has no `needs`; steps with id in the five probes carry
  `continue-on-error: true`; the Report step has `if: always()` and no `continue-on-error`;
  every job declares `timeout-minutes`; `ci.yml` text contains neither `UV_PYTHON` nor `3.15`.
  (The required check's `needs` stay pinned by `tests/guards/test_ci_job_graph.py`.)

Rollback: delete the workflow, the guard, the `_APT_WORKFLOWS` entry and the docs section; no
state outside the repository.
