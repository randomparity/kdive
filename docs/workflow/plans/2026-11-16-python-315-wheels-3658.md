## Task 1 — derive the baseline sizes from the fixture

**Files:** modify `tests/providers/local_libvirt/test_validate_external_artifacts.py`.

**Interfaces:** consumes the module-level `_BZIMAGE_BODY: bytes` (defined at line 104 as
`_bzimage()`) and `_combined_kernel_tar(...)`'s default `module_data=b"\x7fELFmod"`. Nothing
later depends on this task.

**Verification**

- Contract: the baseline evidence's two size fields equal the fixture's real member sizes.
  Mode: focused-test. Test:
  `test_external_boot_evidence_matches_pre_stream_guard_baseline`. Expected red (controlled
  fault): change the derived `vmlinuz_size_bytes` to `len(_BZIMAGE_BODY) + 1` and the test
  fails with a dict-inequality diff on `vmlinuz_size_bytes`. Green:
  `just test-verbose tests/providers/local_libvirt/test_validate_external_artifacts.py`
  exits 0.

**Steps**

1. In the expected dict, replace `"archive_uncompressed_bytes": 1128,` with
   `"archive_uncompressed_bytes": len(_BZIMAGE_BODY) + len(b"\x7fELFmod"),` and
   `"vmlinuz_size_bytes": 1121,` with `"vmlinuz_size_bytes": len(_BZIMAGE_BODY),`.
2. Run the green command; expect pass.
3. Commit; then apply the controlled fault, observe red, `git checkout --` the file.

## Task 2 — refresh the four lock entries

**Files:** modify `uv.lock`.

**Interfaces:** none.

**Verification**

- Contract: the lock carries the four target versions and nothing else moves.
  Mode: focused-test. Command (bash):
  `diff <(git show origin/main:uv.lock | python3 -I -c 'import sys,tomllib; [print(p["name"], p.get("version"), p.get("dependencies")) for p in tomllib.loads(sys.stdin.read())["package"]]') <(python3 -I -c 'import sys,tomllib; [print(p["name"], p.get("version"), p.get("dependencies")) for p in tomllib.load(open("uv.lock","rb"))["package"]]')`
  prints exactly the four `beartype`/`cffi`/`grpcio`/`markupsafe` line pairs (package set,
  versions and dependency edges otherwise identical), and
  `git diff origin/main -- pyproject.toml` is empty.
  `just test-verbose tests/test_dependency_policy.py` exits 0. Pre-state fact: on
  `origin/main` the four packages are at 0.22.9, 2.0.0, 1.81.0, 3.0.3.

**Steps**

1. `uv lock --upgrade-package beartype==0.23.1 --upgrade-package cffi==2.1.1
   --upgrade-package grpcio==1.85.1 --upgrade-package markupsafe==3.0.4`; expect four
   `Updated` lines.
2. `uv sync --locked`; run the verification commands.
3. Commit.
4. At delivery, the PR body states that pyyaml has no cp315 wheel at any release and stays
   source-built in the 3.15 lane, and lists the lock movement beyond the four packages
   (`none` when the check above shows only the four).
