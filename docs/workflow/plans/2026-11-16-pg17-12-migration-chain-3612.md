# PostgreSQL 17.12 fresh-install migration chain (#3612) — plan

**Goal:** a fresh install migrates 0001→0199 on PostgreSQL 17.12+. Databases that applied the
original 0112 keep migrating and lose the row-type hazard. A DB test keeps the hazard from
coming back.

**Architecture:** one exact, allowlisted byte supersession of 0112. A stdlib module
`kdive.db.supersessions` is read by both the runner and the immutability guard. Forward
migration 0199 converts existing databases. A catalog DB test checks the hazard, and the DB
fixture runs on 17.12.
Spec: `docs/workflow/specs/2026-11-16-pg17-12-migration-chain-3612-design.md`.
Decision: `docs/adr/0818-supersede-two-applied-migration-functions-under-a-checksum-allowlist.md`.

**Tech stack:** Python 3.14, psycopg 3.3.4, PostgreSQL 17.12, pytest via `just`, prek.

**Global Constraints**

- PostgreSQL floor stays 14 (ADR-0015). String-body SQL functions are valid there.
- `kdive.db.supersessions` imports only the standard library. The guard runs under bare `python3`
  with no venv (ADR-0015, ADR-0518).
- The only allowed change to `src/kdive/db/schema/0112_capture_operation_supervision.sql` is in
  the two function bodies. Each `\nRETURN <expr>;` becomes `\nAS $fn$ SELECT <expr> $fn$;`,
  with the expression text byte-identical.
- Postgres image: `postgres:17@sha256:0d938e975177bef9f1f61f3f9dbcf2e0aa0a139568f66d3415ed8892eb97f6ac`.
  This is the OCI index; every platform is `PG_VERSION=17.12-1.pgdg13+1`, resolved 2026-11-16
  with `docker buildx imagetools inspect postgres:17`.
- Migration number 0199 and ADR number 0818 are reserved in WORK:SCOPE. Do not renumber.
- Iterate with `just lint`, `just type` and `just test-verbose <path>`. The pre-push hook runs
  the full `just ci`, which takes 9–11 minutes.

Expected implementation size: 330–420 changed lines (L) — the file map below: a module of
about 45 lines, runner and guard edits of about 60, migration 0199 of about 45, about 200 lines
of tests, window-list edits of about 15, and 5 digest lines.

```python
"""Reviewed exceptions to migration byte-immutability (ADR-0015, ADR-0818).

Each entry admits exactly one replacement of one applied migration file: a database that
recorded ``superseded_sha256`` for ``version`` keeps verifying once the file on disk hashes to
``current_sha256``. Nothing else is admitted, and recorded rows are never rewritten.

Standard library only: ``scripts/guards/schema_immutable_guard.py`` imports this module under a
bare ``python3`` with no venv.
"""

from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Supersession:
    """One permitted, exact byte replacement of an applied migration file."""

    version: str
    filename: str
    superseded_sha256: str
    current_sha256: str
    decision: str


SUPERSESSIONS: tuple[Supersession, ...] = ()


def admits(version: str, recorded_sha256: str, current_sha256: str) -> bool:
    """Whether a recorded/on-disk checksum pair is a reviewed supersession of ``version``."""
    return any(
        entry.version == version
        and entry.superseded_sha256 == recorded_sha256
        and entry.current_sha256 == current_sha256
        for entry in SUPERSESSIONS
    )
```

def is_approved(
    entries: Sequence[Supersession],
    filename: str,
    base_sha256: str | None,
    work_sha256: str | None,
) -> bool:
    """Whether replacing ``filename``'s base bytes with its working bytes is listed exactly."""
    return any(
        entry.filename == filename
        and entry.superseded_sha256 == base_sha256
        and entry.current_sha256 == work_sha256
        for entry in entries
    )


def _sha256_at(root: Path, base_ref: str, path: str) -> str | None:
    result = subprocess.run(
        ["git", "show", f"{base_ref}:{path}"], cwd=root, capture_output=True, check=False
    )
    return hashlib.sha256(result.stdout).hexdigest() if result.returncode == 0 else None


def _sha256_of(root: Path, path: str) -> str | None:
    target = root / path
    return hashlib.sha256(target.read_bytes()).hexdigest() if target.is_file() else None


def _approved(root: Path, base_ref: str, name_status: Iterable[str]) -> frozenset[str]:
    entries = _supersessions()
    modified = [
        fields[1]
        for fields in (line.split("\t") for line in name_status)
        if len(fields) == 2 and fields[0] == "M" and _is_schema_file(fields[1])
    ]
    return frozenset(
        path
        for path in modified
        if is_approved(
            entries,
            path.rsplit("/", 1)[1],
            _sha256_at(root, base_ref, path),
            _sha256_of(root, path),
        )
    )

FROM pg_catalog.pg_proc AS p
JOIN pg_catalog.pg_namespace AS n ON n.oid = p.pronamespace

def _add_defaulted_columns(conn: psycopg.Connection) -> None:
    """Both tables accept a defaulted ADD COLUMN; the probe columns are rolled back."""
